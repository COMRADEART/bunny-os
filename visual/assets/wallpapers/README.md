# Bunny wallpaper system

The six wallpaper families are original parametric SVG compositions generated
from `wallpapers.json`. `make visual-build` renders light and dark versions at
16:9, 16:10, ultrawide, and 4K dimensions into `build/visual/wallpapers/`.

The source palette and composition recipe—not generated copies—lives in the
repository. All compositions reserve the upper-left and central working plane,
use paired arc geometry, and avoid copyrighted characters or third-party art.
