repository and are licensed under CC BY-SA 4.0, except where a file states a
different license. No third-party artwork or copyrighted character is included.

direction and a user-provided reference image. They are not included in the
blanket CC BY-SA grant above. Confirm the project's rights to the reference and
record an explicit character-asset license before public redistribution.

does not grant permission to misrepresent another system as an official Bunny
OS release.
