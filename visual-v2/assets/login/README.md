# Login, lock, and session concepts

> VISUAL PROTOTYPE ONLY
>
> NOT RELEASE QUALIFIED
>
> DO NOT MERGE INTO MAIN

These deterministic, character-free SVGs show the intended login, lock, and
session-selection hierarchy. They are not installed as a GDM theme. The login
concept keeps keyboard layout, accessibility, network, power, and session
selection visible; the selector keeps GNOME available and marks Bunny Desktop
Preview as additive.
