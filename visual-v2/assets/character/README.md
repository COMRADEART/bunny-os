# Bunny guide V2 assets

>
> NOT RELEASE QUALIFIED
>
> DO NOT MERGE INTO MAIN

The `bunny-guide/v1/` directory contains the approved 14-pose transparent PNG
family used by Character Mode. Each file has one full-body character on a
1024×1536 RGBA canvas. The manifest records state intent and integrity hashes.

The images were generated with OpenAI image generation from user-provided
visual direction and a user-provided reference, then locally converted from a
flat chroma key to alpha PNGs. Redistribution clearance for the reference has
not been established; the package and final report must state this clearly.
