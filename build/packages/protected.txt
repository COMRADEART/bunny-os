# Packages that must remain installed in every profile that declares them.
#
# build/scripts/install-packages.py verifies this list after applying a
# profile's removePackages, and fails the build if any entry disappeared.
# Minimisation exists to reduce attack surface, not to reduce a scan score, and
# these five categories are exactly where the two motives diverge.
#
# An entry here is not a promise that the package is in every profile. It is a
# promise that if a profile installs it, minimisation will not take it away.
