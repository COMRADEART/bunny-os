# Production signing execution

Phase 17 receives proof of an externally performed production signature; it
does not sign the artifact. Favorable evidence names the submitted and
independently recomputed digests, signer authority, method, signature or
verification artifact, timestamp, verification result, and verification
method. Both digests must name the exact artifact and verification must be
`PASS`. `SIGNING_DRILL` is terminally non-contributing. Private keys and other
credentials are rejected by Phase 9 before publication.
