# Bunny OS foundation demonstration

This package demonstrates Phase 1 on a qualified Fedora/KVM builder. It is a script/checklist, not evidence that the current Windows host built or booted an image. Use only artifacts whose provenance/checksum/SBOM/image inspection gates passed.

Current source state has an explicit Bunny placeholder and disabled updates. Where the demo calls for a verified Bunny runtime or staged update, use a separately reviewed signed artifact/test channel; otherwise show the documented safe refusal/simulation and call it that.
