# Ten-minute demo

1. Boot into Bunny Shell and verify Wayland.
2. Open Launcher with Super+Space.
3. Launch a conventional application.
4. Open a project workspace; show branch/changed-file integration only if real Core data exists.
5. Open Super+B and ask Bunny; with placeholder, show honest unavailable state.
6. Inspect a server-authoritative plan.
7. Inspect running tasks.
8. Approve an exact sandboxed action through Bunny Core, never the shell cache.
9. Open normal Terminal with Super+T.
10. Review/edit a proposed command and show cwd/environment/risk.
11. View notifications and lock-screen privacy.
12. Enable local-only mode; prove cloud calls are denied.
13. Inspect indexed locations, permissions, devices, and telemetry disabled.
14. Inspect OS update signature/staging/rollback separately from Bunny updates.
15. Open recovery settings and previous deployments.
16. Log out and restart into Bunny (Safe Shell); verify conventional repair tools.

Skip steps 5–8 as unavailable if the signed Bunny artifact is absent. Never replace them with fabricated success.
