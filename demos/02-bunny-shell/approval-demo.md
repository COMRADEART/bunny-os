# Approval demo

Requires a signed compatible Bunny artifact and its authenticated Core summary API. Start a sandboxed task that requests one exact workspace file. Open Super+Shift+A and inspect action, task, capability, exact path, reversibility, checkpoint, privilege, destination, expiry, and risk. Exercise Deny, Allow once, and stale expiry in separate fixtures. Confirm no `Always allow everything` option exists.

With the placeholder artifact, the correct result is `Bunny Core is unavailable`; do not inject a fake approval into production state.
