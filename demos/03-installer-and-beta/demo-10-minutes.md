# Ten-minute demo

1. Explain Anaconda Web UI/Blivet/bootc boundaries and the absence of a generic root command.
2. Show the ISO boot-menu definition and offline payload build command.
3. Exercise disk discovery redaction, wrong-disk blockers, identity-bound confirmation, erase/alongside plans, and manual validation.
4. Exercise request tampering, stale/replay/cross-session rejection, secret-field rejection, and fail-closed `install.start`.
5. Show LUKS2/TPM fallback policy and one-time recovery-key confirmation.
6. Show resumable first-run defaults, optional Bunny/provider/model/search/backup, and application permissions.
7. Summarize build/VM/hardware blockers and the Fedora/KVM closure commands.
