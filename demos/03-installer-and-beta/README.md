# Phase 3 installer and beta demonstration

These demonstrations separate source/static behavior from artifact/runtime evidence. On this Windows host only schema, planning, policy, redaction, and unit tests run. Image, installation, encryption, boot, upgrade, rollback, and hardware steps require the documented disposable-disk Fedora/KVM builder and must not be marked passed from screenshots or dry runs.

Start with `make gate-phase-3`. Use only fresh virtual disks for destructive exercises. Never pass a password or recovery key on a command line or copy one into demo notes.
