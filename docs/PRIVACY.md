# Privacy

Telemetry, crash upload, hardware submission, cloud providers, capture, and plugin network access default off. Search starts with no approved locations. Diagnostics are local and redacted; prompts, memories, documents, credentials, recovery keys, Wi-Fi names, and persistent tracking IDs are excluded. Bunny services must not listen publicly or cross user boundaries.

Installed-candidate network, crash, bundle, and multi-user testing has not run. These defaults are source policy, not a completed privacy certification.
