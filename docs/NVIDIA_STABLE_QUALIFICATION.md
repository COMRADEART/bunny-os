# NVIDIA stable qualification

No NVIDIA GPU or driver branch is stable-supported. Qualification must name GPU generations and test open modules, any separately licensed proprietary path, Secure Boot/module signing, Wayland/XWayland, suspend/resume, external displays, hybrid switching, optional acceleration, update, and rollback. Failed signing must leave a bootable open/safe-graphics path.

Proprietary drivers are not bundled. No claim is made until license, redistribution, signature, kernel compatibility, and physical evidence are complete.
