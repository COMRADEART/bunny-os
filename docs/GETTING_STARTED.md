# Getting started

Bunny OS is not currently installable or stable: this repository has source definitions but no signed image. Do not run installer prototypes against real disks. When a signed candidate exists, verify its checksum/signature, compare system requirements and tested hardware, back up data, retain recovery credentials/media, and use a disposable or supported system first.

Bunny remains optional; conventional GNOME applications, Files, Terminal, Settings, updates, and recovery must work without it. See `VERIFY_DOWNLOAD.md`, `INSTALLATION.md`, `KNOWN_ISSUES.md`, and `STABLE_FAQ.md`.
