# Background service audit

`operations/data/service-audit.json` records purpose, trigger, privilege, network access, CPU, memory, failure impact, and default necessity for Bunny units. CPU and memory are unknown until an installed candidate is measured.

The update timer and Bunny Desktop remain disabled/opt-in; search requires approved locations; the broker is local AF_UNIX activation; health and recovery remain available. Performance work must not disable accessibility, recovery, or essential device services. Any enabled-service change requires boot, degraded-mode, network-listener, and accessibility retesting.
