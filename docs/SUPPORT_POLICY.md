# Support policy

Developer images are unsupported engineering inputs. Beta images, if published, receive best-effort fixes until their stated end date and may require a later beta. Stable support duration is **not yet promised**: it will be declared only after maintenance staffing, signing-key continuity, package/kernel lifecycle, update/rollback/recovery capacity, and candidate evidence are approved.

Security fixes are prepared as needed; maintenance and feature cadence remain uncommitted until the same capacity review. Every supported release publishes start/end dates, update path, recovery media, and EOL notice. After EOL the updater clearly reports unsupported state and does not silently jump across an unqualified migration. Offline use remains available, but unsupported software receives no security assurance.
