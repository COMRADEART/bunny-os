# Reporting bugs

Submit affected version, component, steps, expected/actual result, reproducibility, hardware class, firmware/kernel/image version, workaround, and a redacted diagnostic export. Do not include prompts, memories, documents, screenshots with personal content, credentials, recovery keys, Wi-Fi names, serials, or unredacted dumps.

Reports receive a source-preserving ID and may receive an advisory duplicate suggestion. Maintainers confirm severity/merge/closure. Security issues follow the private security contact once established; no public-beta support endpoint is currently provisioned.
