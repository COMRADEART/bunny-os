# Phase 0 → Phase 1 Traceability Matrix

This file is the accountable trace ledger for all sixteen constitutional principles and all seventeen Phase 0 decisions. The controlling sources are [`BUNNY_OS_PHASE_0.md`](../../BUNNY_OS_PHASE_0.md), [`BUNNY_OS_PHASE_1.md`](BUNNY_OS_PHASE_1.md), the [`adr/`](adr/) set, and [`PHASE_2_BACKLOG.md`](PHASE_2_BACKLOG.md). Phase 0 remains authoritative: an ADR or an architecture proposal cannot amend it by itself.

## Reading the ledger

- **Ratified** means the requirement or decision is already controlling in Phase 0.
- **Pending A#** means Phase 1 §31.1 requests a constitutional amendment. None of A1–A15 is adopted in the current record; the existing Phase 0 text continues to control until ratification.
- **Provisional** means Phase 1 contains an architecture proposal whose governing ADR or entry condition is not ratified or satisfied.
- **Unverified** means the required evidence does not yet exist. A specification paragraph is not implementation or conformance evidence.
- **Gap** means the current implementation backlog has no ticket that can produce the named evidence. The gap is recorded rather than covered by an invented backlog ID.
- The **accountable owner** is deliberately singular. Other components named in the architecture or evidence column are contributors, not co-owners.
