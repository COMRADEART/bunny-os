# Hardware compatibility

No physical model is Recommended or Supported. The evidence database has zero submissions. Categories and promotion criteria are in `STABLE_HARDWARE_TIERS.md`; all unlisted systems are Untested. Legacy BIOS and ARM64 are Unsupported by the current design, while proprietary NVIDIA is unqualified.

Future entries must link clean/encrypted install, update, rollback, recovery, graphics, network, audio, suspend/resume, candidate hash, and open issues. Community reports are input for reproduction, not certification.
