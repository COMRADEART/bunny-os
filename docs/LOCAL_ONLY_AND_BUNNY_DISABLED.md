# Local-only and Bunny-disabled qualification

Local-only testing covers no network/provider, with and without a local model, offline applications/docs/recovery/diagnostics, and no cloud fallback. Bunny-disabled testing covers login, apps, terminal, files, settings, network, updates, recovery, application installation, and accessibility using conventional GNOME/Linux facilities.

Both modes must remain useful and recoverable. No installed-candidate execution exists; source architecture alone does not qualify them.
