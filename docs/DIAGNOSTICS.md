# Diagnostics

Diagnostic export is local, optional, bounded, and mode 0600. Review the preview before saving or separately uploading. Approved data includes versions, component states, redacted logs, failure signatures, deployment status, and user-selected hardware metadata. User content, secrets, raw identifiers, prompts/memory, documents, screenshots, and credentials are excluded.

No public upload endpoint is enabled. Manually inspect a sample from every candidate according to `DIAGNOSTIC_SAFETY.md`.
