# Crash-report operations

Crash collection and upload are optional and disabled by default. Approved aggregate fields are component, version, architecture, stack signature, driver, kernel, and deployment version. There is no stable user/device/session identifier, cross-report user profile, prompt, memory, document, path, network identity, or credential.

Triage links aggregate signatures to failure records and issues; it cannot close or reduce severity. Raw dumps remain local unless a separate, reviewed consent flow exists. Retention, deletion, processor, and incident policy must be approved before any public endpoint is enabled.
