# Stable release blockers

Stable is blocked by any unresolved Blocker/Critical, common-path High installer failure, encryption failure/key leakage, wrong-disk defect, update signature bypass, supported-path rollback failure, nonfunctional independent recovery media, cross-user exposure, public Bunny listener, unexplained network activity, inaccessible essential workflow, unsigned artifact, missing checksum, broken supported migration, license violation, missing security support process, or untested release rollback.

Unknown evidence is blocking. A narrowly scoped High issue may remain only when its configuration is explicitly unsupported and common supported paths are unaffected. No acceptance can waive encryption loss, wrong disk, signature, recovery, privacy, accessibility, or cross-user boundaries.
