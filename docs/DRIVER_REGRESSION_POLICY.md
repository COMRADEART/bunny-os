# Driver regression policy

Track known-good/failing/fixed versions for kernel, Mesa, NVIDIA, firmware, Wi-Fi, Bluetooth, audio, and camera, together with affected hardware, workaround, rollback path, and evidence. A hold is temporary, narrowly scoped, visible to the user, and removed after a signed fixed deployment passes the same matrix.

The regression ledger is empty because no candidate or hardware run exists. Empty means unknown, not regression-free.
