# Installer reliability programme

The tracked funnel is live boot, disk probe, automatic layout, encrypted layout, supported unallocated-space dual boot, deployment, bootloader, first boot, and first run. Each attempt must have a signed image identity and independent operation journal. Counts and rates are published only from complete denominators; current rates are unknown because no public-beta attempts exist.

Release-blocking regressions cover wrong-disk selection, partition-table damage, installation-media selection, encryption/key leakage, recovery omission, bootloader fallback, power interruption, and cleanup. Confirmed defects require a synthetic policy test plus a disposable virtual-disk reproduction. Existing Phase 3 tests are source-policy evidence only.
