# Troubleshooting

Because no installable candidate exists, use the host/static commands only. Run `make gate-phase-5` for source validation. `gate-stable-candidate` and `gate-stable-release` should fail until complete signed evidence exists.

For a future installed release, prefer previous deployment, Safe Shell, safe graphics, Bunny/plugin disable, and independently verified recovery media. Preserve logs and transaction journals, redact exports, avoid repeated destructive installer attempts, and do not bypass signature/encryption checks.
