# Stable FAQ

**Is Bunny OS stable?** No. The recommendation is `NO-GO`.

**Can I download it?** No signed public-beta or stable artifact exists in this repository.

**Is my hardware supported?** No physical model is qualified; check the evidence table when a candidate exists.

**Is Bunny required?** No. Stable qualification requires Bunny-disabled and local-only operation.

**Are telemetry and crash uploads enabled?** No; both default off and upload remains optional.

**Can I safely downgrade?** Not yet. Unknown migration/downgrade paths are rejected.

**When is stable?** No date or support duration is promised. Publication requires all protected gates and a `GO` report.
