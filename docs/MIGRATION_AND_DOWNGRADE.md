# Migration and downgrade

Qualify latest/previous public beta, promised developer image, fresh install, and encrypted/unencrypted beta to the exact RC. Compare preservation manifests for user/Bunny/plugin/model/workspace/application/settings/credential-reference/recovery/previous-deployment state.

Downgrade states are deployment rollback, unsupported after irreversible migration, recovery-only, or fresh reinstall. The updater displays the exact state before staging and rejects an unknown route. Current beta-to-stable entries are disabled; no safe automatic downgrade exists.
