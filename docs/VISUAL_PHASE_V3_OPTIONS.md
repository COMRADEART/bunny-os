# Visual Phase V3 options

> VISUAL PROTOTYPE ONLY
>
> NOT RELEASE QUALIFIED
>
> DO NOT MERGE INTO MAIN

The optional next phase is a bounded native Bunny Wayland-shell feasibility
prototype. It should begin only after V2 receives Linux GNOME runtime review,
accessibility review, performance measurements, interaction feedback, and a
character-rights decision.

Candidate investigations are compositor feasibility, native panel and launcher
primitives, window-management policy, input-method compatibility, assistive
technology architecture, multi-monitor behavior, fractional scaling, and a
strict privilege boundary. V3 must remain non-production and must not replace
the qualified desktop or start encrypted-unlock qualification.
